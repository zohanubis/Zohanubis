## <img src="https://api.iconify.design/lucide:user-round-check.svg?color=%230ea5e9" width="22" height="22" alt="Profile" /> About Me

I am a **Software Engineer / Fullstack Developer** with hands-on experience across **frontend and backend development**, specializing in **TypeScript, Java, Next.js, React, Spring Boot, and Go**.

I build production-oriented web applications with a strong focus on:

- **Frontend:** responsive UI, reusable components, Figma-to-code, SEO/GEO-ready Next.js pages, performance optimization.
- **Backend:** REST APIs, Java Spring Boot, Go Chi, authentication, database modeling, modular architecture, documentation.
- **Product delivery:** working closely with backend, frontend, QA, designer, PM, and client-side stakeholders.

Currently, I work as a **Frontend Developer at Cyberskill Software Solutions** on a production e-commerce platform, while also contributing to confidential backend development using **Java and Spring Boot**.
